# Password-Generator

A simple **React-based Password Generator** that allows users to create random passwords with customizable length, numbers, and special characters.

---

## 🔗 Live Project

-Check Out Project Here: [Password Generator]()

---

## 🚀 Features

- Generate random passwords.
- Customize password length (5–25 characters).
- Include/exclude numbers.
- Include/exclude special characters (`+-*/#@()^&!~{}`).
- Responsive and visually appealing UI.

---

## ➡️ Usage

-Move the slider to select the desired password length. 
-Check/uncheck Number or Character options to include/exclude numbers or special characters. 
-Click Change Password to generate a new password instantly.

---

## 🛠️ Technologies Used

-React (with hooks: useState, useEffect, useCallback) 
-HTML5 
-CSS3 
-JavaScript (ES6+)
